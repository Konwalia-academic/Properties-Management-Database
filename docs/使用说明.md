# PMD 个人物品管理数据库 · 使用说明

本文档覆盖：环境要求、本机（localhost）部署、服务器（Debian + Nginx）部署、日常使用、模板与作业单说明、故障排查。

---

## 0. 环境要求

| 组件 | 要求 |
|---|---|
| PHP | 8.1 及以上（CLI 与 FPM 均可） |
| PHP 扩展 | `pdo_mysql`（必需）、`zip`（xlsx 必需）、`mbstring`（推荐）、`json`（内置） |
| MySQL | 5.7 或 8.0+（MariaDB 10.3+ 亦可） |
| Web 服务器 | Nginx（推荐）或 Apache；本机调试可直接用 PHP 内置服务器 |
| 操作系统 | Linux（Debian/Ubuntu 已验证）或 macOS（arm） |

> 项目零第三方依赖、无需 Composer/npm/构建步骤；部署完成后新增体积约 10~30MB。

## 1. 本机部署（localhost）

### 1.1 准备 MySQL

```bash
# macOS（Homebrew）
brew install mysql
brew services start mysql

# Debian/Ubuntu
sudo apt install mysql-server
sudo systemctl enable --now mysql
```

创建数据库与账号（也可留给安装向导自动建库）：

```sql
CREATE DATABASE IF NOT EXISTS pmd DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER IF NOT EXISTS 'pmd'@'localhost' IDENTIFIED BY '你的密码';
GRANT ALL PRIVILEGES ON pmd.* TO 'pmd'@'localhost';
FLUSH PRIVILEGES;
```

### 1.2 启动应用

```bash
cd PMD
php -S 127.0.0.1:5019 -t public public/index.php
```

浏览器访问 **http://127.0.0.1:5019** → 进入安装向导：

1. 检查环境（PHP 版本与扩展），全部 ✔ 后继续；
2. 填写数据库主机/端口/库名/用户名/密码；
3. 设置网站标题与**登录 PIN**（4-32 位，请牢记）；
4. 点击安装 → 自动建表并写入配置 → 跳转登录页。

登录后即可开始使用。安装完成后建议删除 `public/install.php`。

> **一键部署（推荐）**：`bash tools/local_deploy.sh` 可自动建库/建表/写配置/设 PIN，默认端口 **5019**（第 2 个参数或环境变量 `PMD_PORT` 可覆盖端口，如 `bash tools/local_deploy.sh 123456 8080`）。
>
> 其他本机方式：MAMP / XAMPP / Laravel Herd 等集成环境，把站点根目录指向 `PMD/public` 即可。

## 2. 服务器部署（Debian + Nginx）

### 2.1 安装基础软件

```bash
sudo apt update
sudo apt install -y nginx php-fpm php-mysql php-zip php-mbstring mysql-server
php -v          # 确认 >= 8.1
php -m | grep -E "pdo_mysql|zip|mbstring"
```

### 2.2 上传项目

```bash
# 本地打包
cd /path/to
tar czf pmd.tar.gz PMD
scp pmd.tar.gz user@服务器:/tmp/

# 服务器解压
sudo mkdir -p /var/www
sudo tar xzf /tmp/pmd.tar.gz -C /var/www
sudo chown -R www-data:www-data /var/www/PMD
sudo chmod -R 775 /var/www/PMD/app/storage /var/www/PMD/public/uploads
```

### 2.3 配置 Nginx

```bash
sudo cp /var/www/PMD/deploy/nginx.conf.example /etc/nginx/sites-available/pmd
sudo nano /etc/nginx/sites-available/pmd
# 修改 server_name 为你的域名/IP；fastcgi_pass 改为你的 PHP 版本 socket
sudo ln -s /etc/nginx/sites-available/pmd /etc/nginx/sites-enabled/
sudo rm -f /etc/nginx/sites-enabled/default   # 可选
sudo nginx -t && sudo systemctl reload nginx
```

### 2.4 创建数据库并安装

```bash
sudo mysql
CREATE DATABASE IF NOT EXISTS pmd DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER IF NOT EXISTS 'pmd'@'localhost' IDENTIFIED BY '强密码';
GRANT ALL PRIVILEGES ON pmd.* TO 'pmd'@'localhost';
FLUSH PRIVILEGES;
EXIT;
```

浏览器访问 `http://你的域名` → 安装向导（同 1.2）。安装后删除 `public/install.php`：

```bash
sudo rm /var/www/PMD/public/install.php
```

可选：用 certbot 配置 HTTPS：`sudo apt install certbot python3-certbot-nginx && sudo certbot --nginx`。

## 3. 使用指南

### 3.1 序列号说明

- 格式：`3 位字母 + 3 位数字`，如 `NDZ121`。
- 首字母 = 母类别：`R` 容器、`N` 耐用品、`H` 消耗品、`B` 已报废。
- 预置类别中 `R`（容器）与其他母类别一样覆盖全部 16 种子类别；**导入数据遇到不存在的类别组合时系统自动创建**，无需手动在设置中添加（新代码的名称取自预置表，未收录时以代码本身命名，可在设置中修改）。
- 次字母 = 子类别：`BG`办公用品、`QJ`卫生清洁用品、`RH`日化用品、`SN`收纳用品、`WJ`五金工具、`DZ`电子设备、`FS`服饰品、`YP`药品、`SP`食品饮品、`CJ`餐厨用具、`YS`印刷品、`GH`个人护理用品、`ZS`装饰品、`YD`运动器械、`AQ`安全设施、`FZ`其他纺织品（可在设置中扩展）。
- 后 3 位数字同前缀内唯一：新增时自动递增，满 999 自动占用最小空闲组合。
- 手动输入序列号时系统校验格式、类别合法性、唯一性。

### 3.2 新增物品

**方式一 逐项录入**：选择母/子类别 → 序列号自动指派（也可切"手动输入"）→ 填写其他字段（含卫生等级）→ 保存。
**方式二 批量新增**：选定类别、位置与卫生等级 → 选择行数 → 逐行填写名称/品牌/数量/单位/价格 → 保存（自动分配不重复序列号）。
**方式三 文件导入**：上传 `.xlsx` / `.csv` / `.sql` → 预览（标注重复与无效行）→ 选择重复序列号处理方式（**更新已有记录** / **放弃重复行**）→ 应用。
- 序列号留空的行视为新增，需填写母/子类别，系统自动生成序列号。
- 导入与新增/修改都会自动更新"最新修改日期"。

### 3.3 物品总览（查询与批量修改）

- **检索**：输入关键词（序列号/名称/品牌/条形码/备注/位置/容器）或按位置、类别筛选；可勾选"显示已报废"、"仅显示待交换"。
- **列表**：显示每个物品的**卫生等级**（如 `A 食品接触`）；未设置显示 `—`。
- **批量修改**：勾选多行 → 批量修改 → 选择字段与值 → 应用（支持位置、数量、折旧、类别、卫生等级等；改类别时序列号自动重生成）。
- **导出**：Excel / CSV 全库导出（遵循当前筛选条件）。
- 行内操作：编辑（双击行亦可）、标记报废（序列号变 `B` 前缀）、删除。

### 3.4 物资交换作业

1. **查询待移动物品**：按序列号/名称/位置/容器检索；
2. **定义新所在位置代码**：勾选物品 → 选择新位置 → 应用（写入"新所在位置代码"）；
3. **输出物资交换作业单**：点击"生成作业单"下载 `.xlsx`（含序列号、名称、目前/新位置、备注）；可离线编辑；
4. **用户确认完成**：实物移动完成后点击"应用修改"——物品"目前所在位置"更新为新位置，"新所在位置代码"清空。

> 快捷方式：在"上传作业单"区上传同格式作业单（可含多行、可修改过），预览无误后直接应用，跳过步骤 1-2。
> 说明：交换作业不能将位置设为 `LTO`（借出及在途），借出请走物资借还作业。

### 3.5 物资采购作业

1. **定义所在区域**：选择位置（或全部区域）→ 检索该区域中**仓储/折旧情况 < 20%** 的全部物品；
2. **选择需要采购的物品**：勾选并确认采购数量（默认 1）；
3. **检索其他一并采购的物品**：关键词检索补选；
4. **确认新增物品**：如需采购全新物品，点"添加一个本次采购新增的物品"，填写名称、类别与卫生等级（序列号自动生成）；
5. **输出欲购清单**：下载 `.xlsx`（新增物品的序列号已自动分配）→ 采购完成后点击"应用修改"：
   - 已有物品：**余量 += 采购数量、折旧重置为 100%**，备注追加采购记录；
   - 新增物品：按清单入库。

> 快捷方式：上传同格式欲购清单直达应用步骤。

### 3.6 物资借还作业

- **借出**：检索并勾选物品 → 填写借用人 → 确认。系统将物品"目前所在位置"改为 `LTO`，备注追加 `[借出] 日期 借出给 XX`，并写入借还记录。
- **归还**：在"归还"页勾选借出中的物品 → 填写**归还后余量、折旧(%)、所在位置**（可附备注）→ 确认。备注追加 `[归还] 日期 归还…`，记录闭合。
- **记录**：查看全部借还历史（含归还状态）。

### 3.7 设置

- **常规**：网站标题（左上角与浏览器标题）、LOGO 上传/移除、主题色（颜色选择器）、每页条数、语言（当前仅简体中文，接口已就绪，见 readme 第五节）、登录 PIN 修改。
- **类别代码管理**：增删改母类别×子类别组合（被物品使用的组合不可删除）。新增子类别后即可在录入时选择；导入数据自动创建的组合也会出现在这里，可修改名称。
- **位置代码管理**：维护位置代码（2-4 位字母）与名称；`LTO` 为系统保留（借出及在途），不可删除或改名。系统预设 13 个位置代码（通辽住所 FA-FE、通辽 TL、长株潭 CZT、南京 NJ、苏州 SZ、上海 SH、沈阳 SY、武汉 WH、借出及在途 LTO），可新增、可修改。
- **卫生等级管理**（位于「位置代码管理」之后）：维护卫生等级方案（单个大写字母 + 名称 + 排序）。预置 `A`食品接触、`B`母婴与敏感部位接触、`C`皮肤接触、`D`地面与脏污材料接触，可新增自定义等级、改名、删除或调整排序。导入数据遇到未登记的等级时自动创建并显示于此。删除等级不影响已引用该等级的物品（名称将显示为等级代码）。

## 4. 模板与作业单

| 文件 | 用途 |
|---|---|
| `templates/物品导入模板_items_import_template.xlsx / .csv` | 物品数据导入（表头见下） |
| `templates/物资交换作业单模板_exchange_worksheet_template.xlsx` | 交换作业单（可上传回系统） |
| `templates/物资采购欲购清单模板_purchase_list_template.xlsx` | 采购欲购清单（可上传回系统） |
| `sql/import_template.sql` | SQL 数据导入模板（仅执行 `INSERT INTO items` 语句） |

**物品导入表头**：序列号、物品名称、品牌、目前所在位置代码、新所在位置代码、所在容器序列号、购入价格、余量、季度消耗量、单位、仓储/折旧情况(%)、备注、物品母类别、物品子类别、商品条形码、卫生等级

**交换作业单表头**：序列号、物品名称、目前所在位置代码、新所在位置代码、备注

**采购欲购清单表头**：序列号（新增留空）、物品名称、品牌、物品母类别、物品子类别、目前所在位置代码、单位、当前余量、采购数量、购入价格、备注、卫生等级（仅新增物品生效）

> 模板可在系统内随时下载（"新增物品-导入"、"交换/采购"页面），也保存在 `templates/` 目录。
> 如需修改列定义后重新生成模板：`php tools/generate_templates.php`。

## 5. 数据备份

- 页面导出：物品总览 → 导出 Excel/CSV。
- 数据库级：`mysqldump -u pmd -p pmd > backup_$(date +%F).sql`；恢复：`mysql -u pmd -p pmd < backup.sql`。
- 建议配合 crontab 定时备份（示例，每日 2:00）：
  ```bash
  0 2 * * * mysqldump -u pmd -p'密码' pmd | gzip > /var/backups/pmd_$(date +\%F).sql.gz
  ```

## 6. 故障排查

| 现象 | 处理 |
|---|---|
| 安装页提示缺扩展 | `sudo apt install php8.2-mysql php8.2-zip php8.2-mbstring`（版本按 `php -v`） |
| 数据库连接失败 | 检查 `app/config.php` 中的 host/端口/账号；确认账号有该库权限 |
| 导入 xlsx 报"无法打开" | 文件必须为 Office 打开生成的 `.xlsx`（非 .xls）；旧版 .xls 请另存为 .xlsx 或 .csv |
| CSV 中文乱码 | 系统自动识别 UTF-8/GB18030；若仍乱码请将文件另存为 UTF-8 |
| 类别/位置中文乱码（升级旧版后） | 运行 `php tools/repair_charset.php` 一键修复全库二次编码乱码 |
| 忘记登录 PIN | 删除 `app/config.php` 后访问 `/install.php` 重置（数据保留） |
| 从 v1.x 升级到 v3.0.1 | 先上传新版本全部代码文件，再把单文件 `upgrade_301.php`（项目根目录下）放到网站根目录 `public/` 并浏览器打开、点「执行升级」——自动为 `items` 表添加 `hygiene_level` 列、新建 `hygiene_levels` 表并写入预置等级，幂等可重复执行，不改动现有设置与数据。若未找到 `app/config.php`，页面会提示填写数据库连接信息。旧数据卫生等级留空，可在编辑时补充。 |
| 页面样式/功能异常 | 强制刷新（Cmd/Ctrl+Shift+R）；检查浏览器控制台报错 |
| 上传文件过大 | Nginx `client_max_body_size` 与 PHP `upload_max_filesize`/`post_max_size` 同步调大 |

## 7. 安全建议

1. 部署完成后删除 `public/install.php`；
2. 数据库账号使用强密码，不要使用 root；
3. 建议启用 HTTPS（certbot）；
4. 定期备份数据库；
5. 登录 PIN 不要与其他系统共用；登录接口内置失败限速（连续 5 次错误锁定 60 秒）。
